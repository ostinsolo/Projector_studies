# Video Diagnostic Validation

## Diagnostic animation

Generated by `procam_calibrate.video_playback.generate_diagnostic_frame` / `write_diagnostic_video`.

Includes:

- white outer rectangle and inset safe-area rectangle;
- square grid;
- large central circle and smaller circles on both walls;
- travelling horizontal, vertical, and diagonal lines;
- moving square that crosses the wall fold;
- corner labels, centre crosshair, frame counter;
- wall A / wall B labels;
- optional seam marker;
- excluded-ceiling overlay available via mask self-check / debug overlays.

The diagnostic must run (or be generated) before trusting user-video playback.

## Camera-based measurements (physical)

Capture diagnostic frames from the fixed audience camera. Measure:

- outer rectangle corner error;
- H/V edge deviation and orthogonality;
- aspect-ratio error;
- circle eccentricity;
- grid cell size variation;
- seam discontinuity;
- ceiling content leakage;
- usable-area and projector-resolution utilisation.

## Initial physical gates

| Metric | Gate |
|--------|------|
| Median geometric error | ≤ 5 cam px |
| P95 geometric error | ≤ 12 cam px |
| Seam median / p95 mismatch | ≤ 3 / ≤ 6 cam px |
| Outer-edge angular error | ≤ 0.25° where measurable |
| Orthogonality error | ≤ 0.5° |
| Aspect-ratio error | ≤ 1% |
| Ceiling leakage | ≤ 0.1% of active video pixels |
| Topology | No mirror/invert; no mask gap across fold |
| Containment | Rectangle inside confidence-adjusted usable region |

Report both **straightness** and **% of available geometry used**.

## Software self-check

`prepare_playback_calibration` warps a diagnostic sample and writes `ceiling_leakage_selfcheck.json` (pass if leak fraction ≤ 0.001).
